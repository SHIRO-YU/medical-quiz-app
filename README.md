# 🏥 医学試験対策クイズアプリ

医学生向けの総合試験対策クイズアプリケーションです。複数の問題セットから選択して学習できます。

## ✨ 主な機能

- 📚 **複数の問題セット対応** - 起動時に問題セットを選択
- 🎲 ランダム出題
- 📱 モバイルファースト設計
- 🌙 ダークモード対応
- 📊 リアルタイム進捗表示・正答率計算
- 💾 セッション管理（リロードしても継続可能）
- 📖 詳細な解説と間違えやすいポイント表示
- 🖼️ 画像対応（問題IDに対応した画像を自動表示）

## 🚀 クイックスタート

### ローカルで実行する場合

1. **リポジトリをクローン**
```bash
git clone https://github.com/あなたのユーザー名/medical-quiz-app.git
cd medical-quiz-app
```

2. **依存パッケージをインストール**
```bash
pip install -r requirements.txt
```

3. **アプリを起動**
```bash
streamlit run app.py
```

ブラウザで `http://localhost:8501` が自動的に開きます。

## 📝 問題セットの追加方法

### 1. CSVファイルの作成

`question_sets/` フォルダに以下の形式のCSVファイルを配置してください：

```csv
問題ID,問題文,選択肢A,選択肢B,選択肢C,選択肢D,選択肢E,正解,解説,間違えやすいポイント
Q001,問題文をここに記載,選択肢Aの内容,選択肢Bの内容,選択肢Cの内容,選択肢Dの内容,選択肢Eの内容,A,正解の解説,注意すべきポイント
```

### 必須カラム

- **問題ID**: 問題を識別するID（例: Q001, Q002）
- **問題文**: 出題する問題
- **選択肢A〜E**: 5つの選択肢（すべて必須）
- **正解**: A, B, C, D, Eのいずれか
- **解説**: 正解の理由や詳細説明
- **間違えやすいポイント**: 受験生が注意すべき点

### 2. 画像の追加（オプション）

1. `images/` フォルダを作成
2. 画像ファイル名を問題IDと同じにする（例: `Q001.png`, `Q002.jpg`）
3. 対応形式: PNG, JPG, JPEG, GIF, WEBP

## 🎯 使い方

1. アプリを起動
2. **問題セットを選択**（サンプル問題、予想問題など）
3. **出題数を選択**（5問、10問、20問、全問、またはカスタム）
4. 問題に回答
5. 解説と間違えやすいポイントを確認
6. 「次の問題へ」で続ける

## 🌐 Streamlit Cloudへのデプロイ

### 1. GitHubリポジトリにプッシュ

このプロジェクトをGitHubにアップロードしてください。

### 2. Streamlit Cloudにログイン

[Streamlit Cloud](https://streamlit.io/cloud)にアクセスし、GitHubアカウントでログインします。

### 3. アプリをデプロイ

1. 「New app」をクリック
2. リポジトリ、ブランチ、メインファイル（`app.py`）を選択
3. 「Deploy!」をクリック

数分でアプリが公開されます。
